### How to Run on Your iPhone 16 Pro (In 2 Minutes)

1. Open your terminal in VS Code (or PowerShell) and navigate into this folder:
   ```bash
   cd c:\Users\PC\Downloads\empirecodes_edit_now\empirecodes_mobile_app
   ```

2. Install dependencies (first time only):
   ```bash
   npm install
   ```

3. Start the Expo server:
   ```bash
   npx expo start
   ```

4. **Open on your iPhone 16 Pro:**
   - A large QR code will appear in your terminal.
   - Open your iPhone's **Camera** or the **Expo Go** app you just downloaded.
   - Scan the QR code.
   - The app will load instantly on your phone!
